# 二、加入与退出

## 加入规则



### 加入方式

加入 Simplicity Studio 共有以下方式：

1. 通过QQ或共创世界，向 Simplicity Studio 提交加入申请，并通过[入室考核](https://kicmtoq4ozt.feishu.cn/wiki/UhSlwzUdri1MwfkmZT8cUIbinFe#share-Wuj0dDNEgoP7a1xZaZhcB0hrn6g)；

2. 受 Simplicity Studio 正式成员邀请，并通过管理员审核。



### 入室考核

非受邀者加入 Simplicity Studio 需要通过入室考核。考官由 Simplicity Studio 管理员担任。

入室**考核流程**如下：

1. 考官浏览申请者的社区主页，体验作品、浏览文章，对申请者进行初步测试；

2. 若初试通过，考官将通过QQ在线访谈等形式，向申请者询问相关问题，进一步了解情况；

3. 根据申请者应答情况完成最终判断（不符合标准/符合见习成员标准/符合正式成员标准）。



**考核标准**随工作室需求而不定期变更。当前（2024\.12\.28）考核标准如下：

> 2023\.5\.27 考核标准：[simplicity studio 成员行为与能力评价表](https://kicmtoq4ozt.feishu.cn/wiki/Wuz1wDQjRiZ9GEkdR2acdSovnib)

## 退出规则

退出 Simplicity Studio 分为成员主动退出和被工作室请出。

### 主动退出

当成员需要主动退出 Simplicity Studio ，可向管理员发送申请。

若成员当前无项目制作任务，可直接退出。
若有正在参与的项目，需将项目完成，或经管理员同意后，方可退出。

违反主动退出规则者将影响未来重新加入或合作信誉。

### 被工作室请出

工作室成员可能因为以下原因被工作室请出：

- 严重违反工作室规则

- 能力低于最新成员标准

- 特殊需要

# 三、成员等级

Simplicity Studio 成员分有多个等级。不同等级标准及权利如下：

\*下述所有精华作品默认采用稽木世界精华作品体系

## 见习成员

**等级标准**

- 有在未来完成一份初精的潜力

- 具有某一方面的特长

- 长期活跃，年龄偏小

**享有权利**

- 学习基础知识与合作方法

- 接受正式成员的指导

- 参与项目制作

见习身份给予每一位希望加入 Simplicity Studio 但暂时能力不足或合作能力有待考核的创作者。

见习成员将获得为期30天的**见习期**，期间可学习基础与合作知识。

见习期间，管理员将进一步观察见习成员的能力（尤指活跃情况、合作能力与意愿）。

见习结束后，管理员将评判见习成员是否符合正式成员标准，并决定见习成员的转正或离开。

## 正式成员

**等级标准**

**新秀型成员：**

- 有制作初精的能力

- 具有某一方面的特长

- 具备广阔的发展前景（长期活跃，年龄偏小）

- 积极参与工作室项目制作

**II型成员：**

- 已有一份等质于中精的作品

- 全能或在某一方面远超常人

- 具有良好的团队创作能力

**享有权利**

- 参与所有项目制作

- 加入 Simplicity Studio 飞书群

- Game Jam 辅助组队与创作指导

- 获得工作室所有项目源码

- 活动奖励

## **管理员**

**等级标准**

- 达到正式成员标准

- 为工作室项目制作作出大量贡献

- 近期保持活跃与贡献

- 良好的管理能力、责任心与归属感

**享有权利**

- 所有正式成员的权利（管理员属于正式成员）

- 开展入室考核

# 四、成员守则

1. Simplicity Studio 允许成员拥有多室籍。
此项规则不代表您可以违反其它工作室的单室籍规定而同时加入 Simplicity Studio。

2. Simplicity Studio 保护自己的组织机密。未经允许，禁止保存、复制、传播 Simplicity Studio QQ群、飞书群及其旗下项目群、线下讨论等任何渠道的聊天记录、项目资讯、版权素材等任何信息，无论您是否为 Simplicity Studio 正式成员。

3. 成员在享有工作室资源与权益的同时，须积极参与工作室项目讨论与技术实践，主动维护集体创作氛围。
成员不得以 Simplicity Studio 名义从事商业牟利、技术剽窃或损害工作室声誉的行为。

4. 若成员参与的外部项目、商业活动或第三方合作与工作室存在潜在利益冲突，须在知悉后立即内向项目管理员报备。工作室保留根据冲突性质调整成员权限、项目分工或室籍状态的权利。
